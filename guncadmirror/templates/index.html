GunCAD Mirror configuration
Configuration Variable Value Description
API Endpoint {{ mirror_api_endpoint }} The API endpoint to check for releases. Defaults to the main production GunCAD Index instance. Can be changed if you want to mirror a subset of releases.
Assemble Files {{ mirror_assemble_files }} Whether or not files should be assembled in addition to being stored as blobs. This feature doubles disk space usage.
Enable web UI {{ mirror_enable_webui }} If this is disabled you should have several concerning questions.
Basic system/application statistics
Stat Value Description
Known sd_hashes {{ seen_sd_hashes }} hashes This is the number of files you're seeding. Number of known sd_hash variations. Correlates to the number of releases downloaded, but can increase beyond it if someone updates their files.
CPU Usage {{ psutil_cpu }}% Overall system CPU usage across all cores.
Memory Usage {{ psutil_mem }}% Overall system memory usage.
Disk Usage {{ psutil_disk.percent }}%, {{ psutil_disk.free | humanize_bytes }} free Overall system disk space usage for whatever filesystem is at /data. Directly governs how much space GunCAD Mirror has to play with.
Network statistics
Stat Value Description
Bytes Out {{ psutil_net.bytes_sent | humanize_bytes }} Number of bytes sent out since the application was started. Resets if you restart GunCAD Mirror. Also counts hits against this web UI, bear in mind.
Bytes In {{ psutil_net.bytes_recv | humanize_bytes }} Number of bytes received from the network since the application was started.
Errors Out {{ psutil_net.errout }} errors Number of errors encountered when attempting to send data to the network.
Errors In {{ psutil_net.errin }} errors Number of errors encountered when attempting to download data from the network.
Drops Out {{ psutil_net.dropout }} packets Number of packets that we attempted to send but were dropped by the network. High amounts of these indicate a pretty serious network connectivity issue.
Drops In {{ psutil_net.dropin }} packets Number of packets dropped we attempted to download but were dropped for some reason or another.

This page displays statistics for a locally-hosted GunCAD Mirror instance. For information on what these things do or for help configuring your instance, join our Matrix Space or ping me on Twitter.
